# TypoTest - Typing Speed Test Application

TypoTest is a web-based typing speed test application designed to help users improve their typing speed and accuracy. The application provides a user-friendly interface where users can practice typing random paragraphs and receive real-time feedback on their performance, including words per minute (WPM), characters per minute (CPM), and the number of mistakes made.

## Features

- **Random Paragraphs**: The application generates random paragraphs for typing practice, ensuring a unique experience each time.
- **Real-Time Feedback**: Users receive instant feedback on their typing speed (WPM), accuracy (CPM), and the number of mistakes made.
- **Timer**: A 60-second timer counts down, allowing users to track their progress and challenge themselves to improve.
- **Interactive Keyboard**: The on-screen keyboard highlights the keys as they are pressed, providing visual feedback and helping users learn key placement.
- **Result History**: The application keeps track of the last five attempts, displaying WPM, CPM, and mistakes for each session.
- **Reset Functionality**: Users can reset the test at any time to start a new typing session.

## How to Use

1. **Start Typing**: As soon as the page loads, the timer starts, and you can begin typing the displayed paragraph.
2. **Real-Time Feedback**: As you type, the application will highlight correct and incorrect characters, and update your WPM, CPM, and mistake count in real-time.
3. **On-Screen Keyboard**: The on-screen keyboard will highlight the keys you press, helping you keep track of your typing.
4. **View Results**: After the timer runs out, your results (WPM, CPM, and mistakes) will be saved and displayed in the results list.
5. **Try Again**: Click the "Try Again" button to reset the test and start a new typing session.

## Files Overview

- **index.html**: The main HTML file that structures the application, including the input field, result details, and on-screen keyboard.
- **type.css**: The CSS file that styles the application, including the layout, colors, and interactive elements.
- **type.js**: The JavaScript file that handles the logic of the application, including paragraph generation, typing validation, and result calculation.
